# piutang_rsba
adalah aplikasi manajemen pencatatan piutang dan transaksi medis berbasis PWA (Progressive Web App) yang dirancang untuk bekerja secara 100% Offline. Aplikasi ini dibuat oleh bang Doel untuk mempermudah monitoring, pencatatan, serta pembuatan laporan pelunasan piutang pasien secara cepat, aman, dan efisien tanpa ketergantungan pada koneksi internet
